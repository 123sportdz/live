ما الذي يقيسه هذا التقدير، وما الذي لا يفعله

يقيس ما يعرفه المشروع فعلاً: حقوق المصدر، وجود طبقة تحريرية أصلية، الموسيقى، حساسية الموضوع، طول الجلسة، الفجوات، وجودة البيانات الوصفية. كل عائق يظهر مع إجراء عربي محدد.

لا يقرأ تقدير YouTube نفسه؛ التقدير محلي. لكن أثناء البث يعرض زر «حالة بث YouTube» حقل eligibleForAdsMonetization الذي تنشره YouTube للبث المباشر، إن كان متاحاً لحسابك. لا يتجاوز سياسة ولا يعيد صياغة عنوان للتهرّب من تصنيف، والإعلانات المحدودة في الأخبار الحساسة نتيجة متوقعة لا خطأ تقني.

الملفات المحلية: ads-audit.jsonl وsessions.jsonl داخل مجلد الحالة، بصلاحيات 600.

أدخل رابط LIVE لا رابط فيديو. إذا كان بثك لا يظهر إلا بعد تسجيل الدخول إلى TikTok، سجّل الدخول في Chrome أو Edge على جهاز المرحّل ثم اختر المتصفح في «الإعدادات المتقدمة».


هذا الحقل يحدد أخطر عائق: المحتوى المعاد استخدامه. كن صادقاً؛ التقدير لحمايتك لا لمجاملة القناة.

اختر «مفتاح ثابت» ليتجاهل البرنامج OAuth ويدفع مباشرة إلى مفتاح Studio (فعّل Auto-start هناك).




عند ربط YouTube عبر OAuth يُستخدم الوضع التلقائي ويُتجاهل هذا المفتاح.




Facebook
اكتب me للملف الشخصي، أو رقم الصفحة مع رمز وصول الصفحة.
رمز User/Page Access Token (يبدأ بـEAA) يفعّل الإنشاء التلقائي للبث. اتركه فارغاً لوضع المفتاح الثابت.
من Live Producer: إعدادات → مفتاح البث الدائم. يُستخدم هذا المفتاح عندما لا يوجد رمز API.


مهم: مفتاح RTMP وحده لا يتجاوز زر «بدء البث» في Live Producer. للبث التلقائي يجب استخدام رمز Meta API وصلاحيات النشر المناسبة؛ عندها ينشئ البرنامج حدث LIVE_NOW بنفسه، ثم يبدأ البث بمجرد وصول الفيديو. الرمز يبقى محلياً ولا يظهر بعد حفظه.
من Meta Access Token Tool استخدم User Access Token للملف الشخصي أو Page Access Token للصفحة؛ لا تستخدم App Token. احفظ الإعدادات أولاً؛ فالفحص يستخدم الرمز والهدف المحفوظين فقط. الفحص قراءة فقط: يؤكد أن الرمز يصل إلى الهدف المحدد، لكنه لا ينشئ بثاً ولا يضمن وحده امتلاك صلاحيات النشر.
